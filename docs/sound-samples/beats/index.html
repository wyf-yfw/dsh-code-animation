卡点强弱的四种做法

四段用的是同一段铺底、同一组重击、同样的 1.5 / 3.0 / 4.5 秒三个卡点。 四段都做了峰值归一化，响度一致。所以「卡点明不明显」的差别只来自做法本身。

A · 平铺直叙
铺底一直在响，重击只加了一点点。最容易出问题的版本。
B · 把重击拧大声
重击音量翻倍，另加吊镲。铺底完全没动。
C · 卡点前留出静默缺口
卡点前 90 毫秒铺底切到几乎无声，重击落进这个空档，之后铺底回来。
D · 缺口 + 进拍扫频 + 尾音
在 C 的基础上，缺口里加一段上扬扫频，重击带吊镲尾音。
按 A → B → C → D 的顺序听。
重点对比 B 和 C：两段重击都很大声，但 C 应该更容易听出卡点落在哪一刻。
如果 C 也不对，告诉我差在哪：缺口太长或太短、重击音色不够炸、 或者你想要的其实是整体律动更强而不只是孤立的重击。
