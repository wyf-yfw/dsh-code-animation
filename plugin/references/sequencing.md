# 编排

单帧好看不算片子。整条片子的节奏，靠的是场景之间的长短、轻重、疏密。

这一份讲：时间轴怎么切、节奏怎么排、一场戏该有多长、什么时候该停。

---

## 一、先把时间轴画出来

写代码之前，先在纸上（或脑子里）排一条时间轴：

```
0.0 ─ 2.4   开场：logo + 标题
2.4 ─ 3.6   数据：三个数字滚动
3.6 ─ 6.0   演示：界面操作
6.0 ─ 7.2   结论：一句话
7.2 ─ 8.0   收尾：logo 淡出
```

每段写清三件事：起止时间、这一场要说什么、观众该看哪里。

**没有这条时间轴就开始写代码，十有八九写到一半发现时长不够或节奏拖沓。**

---

## 二、一场戏多长

| 类型 | 时长 | 说明 |
|---|---|---|
| 卡点镜头 | 0.4–0.8s | 一闪而过，配合重音 |
| 信息镜头 | 2–4s | 读一句话 + 看一张图 |
| 演示镜头 | 3–6s | 操作流程，要有过程 |
| 情绪镜头 | 2–5s | 慢，留白 |
| 收尾 | 1–2s | logo / 口号 |

一条 30 秒的片子，通常 6–10 个镜头；48 秒的片子 8–12 个。

镜头少于 5 个会显得空，多于 15 个会显得碎。

---

## 三、节奏曲线

好片子不是匀速的。典型的曲线：

```
强度
 │        ╱╲
 │   ╱╲  ╱  ╲╱╲
 │  ╱  ╲╱       ╲
 └────────────────── 时间
   开场  铺垫  高潮  收尾
```

- **开场**（前 15%）：抓注意力，节奏快
- **铺垫**（15%–45%）：给信息，节奏中等
- **高潮**（45%–80%）：最密、最亮、最响
- **收尾**（80%–100%）：迅速降下来

全程一个强度，观众 10 秒就腻了。

---

## 四、疏密

| 密度 | 表现 | 用在哪 |
|---|---|---|
| 密 | 多个元素同时动、信息多、切得快 | 高潮、卖点罗列 |
| 疏 | 一个元素、大片留白、慢 | 开场、转折、收尾 |

**密之后必须有疏**，否则观众疲劳。连续 10 秒高密度，后面再炸也没感觉。

---

## 五、转场的节奏

| 段落 | 转场 |
|---|---|
| 开场 → 铺垫 | 硬切或快速擦除 |
| 铺垫内部 | 硬切为主 |
| 铺垫 → 高潮 | 叠化或闪白（有仪式感） |
| 高潮内部 | 硬切，越快越好 |
| 高潮 → 收尾 | 慢叠化（0.6s） |

---

## 六、开头三秒

观众决定要不要看下去，就看这三秒。

三种有效开场：

1. **直接给结果**：先放成品画面，再解释怎么来的
2. **反常识提问**：一句话制造信息缺口
3. **强视觉**：一个高密度的画面，先抓住眼睛

三种无效开场：

1. logo 旋转三秒
2. 「大家好，今天我们来聊聊……」
3. 缓慢的淡入 + 空镜

---

## 七、结尾

结尾只做一件事：**把话说完**。

| 做法 | 效果 |
|---|---|
| 一句话 + 留白 1s | 干净 |
| logo 淡入 | 品牌感 |
| 回到开场画面 | 闭环 |
| 加二维码 / 链接 | 转化（但别超过 2s） |

**不要在结尾堆信息**。观众这时候已经准备划走了。

---

## 八、和配乐的关系

| 段落 | 配乐 |
|---|---|
| 开场 | 起势（rise），不要一上来就满 |
| 铺垫 | 铺底 + 稀疏节奏 |
| 高潮 | 最满，重音密集 |
| 收尾 | 只留和弦，散开 |

配乐的密度曲线必须和画面的密度曲线一致。画面在收，音乐还在炸，就是「两张皮」。

---

## 九、自检清单

- [ ] 写代码前有完整时间轴？
- [ ] 镜头数在 6–12 之间？
- [ ] 强度曲线有起伏（不是全程一样）？
- [ ] 密之后有疏？
- [ ] 开头三秒有钩子？
- [ ] 结尾只做一件事？
- [ ] 配乐密度和画面密度一致？
- [ ] 总时长和分镜一致（叠化有没有偷走时间）？
