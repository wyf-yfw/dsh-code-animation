# 音画同步

画面和声音各做各的，观众一眼就能看出「配乐是贴上去的」。同步是剪出来的，不是碰出来的。

这一份讲：卡点用哪套时间、声音怎么分线、落点差几毫秒会被听出来、混音电平怎么定。

---

## 一、两套时间

| 时间 | 来源 | 精度 | 用途 |
|---|---|---|---|
| `cuts` | 分镜切点 | 秒（0.01） | 段落结构 |
| `cues` | 分镜里的镜头重点 | 秒（0.01） | 镜头内动作 |
| `beats` | 你从动画代码里导出 | 毫秒（0.001） | **卡点** |

`cuts` 只告诉你「第 3.6 秒换场」，`beats` 告诉你「第 3.617 秒标题砸下」。

**每写完一段动画，把里面真正「炸」的时刻抄进 `beats`。** 文字砸下、数字跳到、
粒子聚拢、故障闪一下——这些才是观众会跟着抖的点。

```json
{ "time": 3.617, "type": "impact", "label": "中文标题砸下", "power": 0.95 }
```

`power` 决定配乐里这一下的力度档位：0.8 以上当重击，0.4–0.8 当强调，0.4 以下当轻点。

---

## 二、两条总线

配乐代码拿到两个出口：

| 形参 | 接什么 | 处理 |
|---|---|---|
| `dest` | 重音、打击乐、转场冲击 | 原样输出，不衰减 |
| `bed` | 铺底、旋律、和弦、律动 | 每个卡点前后被侧链下压 |

```js
// 铺底接 bed
pad.connect(bed);
// 重音接 dest
kick.connect(dest);
```

分线错了，重音就淹在自己的伴奏里，怎么调音量都没用。

### 侧链的时间常数

`bed` 的下压由 `beats` 驱动，形状是：

| 阶段 | 时长 | 增益 |
|---|---|---|
| 提前量 | 80–120ms | 1.0 → 0.25 |
| 重音瞬间 | 0 | 0.2 |
| 恢复 | 180–260ms | 0.2 → 1.0 |

提前量太短（<50ms）听不出「让位」，太长（>200ms）会觉得音乐在喘。

## 三、落点

| 偏差 | 听感 |
|---|---|
| 声音早 1 帧（33ms） | 抢，像音效先到 |
| 完全同帧 | 准，有力量 |
| 声音晚 1 帧 | 稍微钝，但可接受 |
| 声音晚 2 帧以上 | 散，像两条轨没对上 |

所以：**声音事件用 `start(b.time)` 精确落点，不要四舍五入到拍上。**

```js
const t0 = ctx.currentTime;
for (const b of beats) {
  if (b.type === 'impact') kick(t0 + b.time, b.power);
}
```

---

## 四、留白

不是每一秒都要有声音。整条片子里留 2–3 处 0.5s 的静默，重音才有分量。

| 位置 | 效果 |
|---|---|
| 情绪转折前 | 屏息感 |
| 高潮前一拍 | 蓄力 |
| 结尾前 | 收束 |

静默不要放在段落中间——那会像掉帧或音轨断了。

## 五、电平

| 元素 | 峰值 | 说明 |
|---|---|---|
| 铺底（bed） | −18 dBFS | 比人声/字幕低很多 |
| 重音（dest） | −6 ~ −3 dBFS | 要能「跳出来」 |
| 整体峰值 | ≤ −1 dBFS | 留 1dB 余量，不削波 |
| 结尾 | 0（静音） | 最后 0.3–0.5s 自然衰减 |

```js
const master = ctx.createGain();
master.gain.value = 0.9;          // 留余量
master.connect(dest);
```

硬切音频在播放器里会有「啪」的爆音。**所有声音都要在 `duration` 内自然收尾**：

```js
const fade = ctx.createGain();
fade.gain.setValueAtTime(1, t0 + duration - 0.4);
fade.gain.linearRampToValueAtTime(0, t0 + duration);
```

## 六、音效设计

### 6.1 转场音效

| 转场 | 音效 | 时长 |
|---|---|---|
| 硬切 | 短促 kick / hit | 0.15–0.25s |
| 擦除 / 推 | 上行扫频 whoosh | 0.25–0.4s |
| 叠化 | 不需要 | — |
| 闪白 | 白噪声瞬态 + 低频撞击 | 0.2s |

扫频不要做低频（见 timbre 里的硬禁令），用中高频的噪声过带通。

### 6.2 文字音效

逐字出现时给每个字一个极轻的 tick（−30dBFS），整句一次性给一个 whoosh。
**不要每个字都给重音**，那会变成打字机噪音。

### 6.3 数字滚动

滚动过程中给一条持续的低频嗡鸣（随进度升调），落定时给一记 hit。

## 七、和画面的关系

| 画面 | 声音 |
|---|---|
| 静止 | 可以有声音（呼吸、底噪） |
| 快速运动 | 必须有声音（whoosh / 律动） |
| 切点 | 必须有重音，否则切点「软」 |
| 留白 | 最好静音，或只有极轻底噪 |

**画面在动、声音是空的**，观众会觉得「卡了」。
